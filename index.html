SILNIK GENEROWANIA FAKTUR (AUTO-INVOICER) Wklej ten moduł do swojego projektu. Automatycznie tworzy profesjonalne PDFy gotowe do zaksięgowania. ```python from reportlab.pdfgen import canvas def create_invoice(invoice_number, client_name, amount, output_path): c = canvas.Canvas(output_path) c.drawString(100, 800, f"FAKTURA NR: {invoice_number}") c.drawString(100, 780, f"Klient: {client_name}") c.drawString(100, 760, f"Kwota do zapłaty: {amount} PLN") c.drawString(100, 740, "Termin płatności: 7 dni") c.drawString(100, 720, "Konto: 41 2910 0006 0000 0000 0529 4580") c.save() print(f"[SYSTEM] Faktura {invoice_number} wygenerowana dla {client_name}.") # Przykładowe wywołanie # create_invoice("2023/10/001", "Firma X", 1500, "faktura_001.pdf") ``` ### 2. AUTOMATYCZNY MODUŁ WYSYŁKI (EMAIL-GHOST) Ten skrypt "podaje" fakturę klientowi prosto na skrzynkę. ```python import smtplib from email.message import EmailMessage def send_invoice_email(client_email, file_path): msg = EmailMessage() msg['Subject'] = 'Faktura za usługi IT' msg['From'] = 'twoja-firma@example.com' msg['To'] = client_email msg.set_content('W załączniku przesyłam fakturę za wykonane usługi. Proszę o przelew na wskazane dane.') with open(file_path, 'rb') as f: file_data = f.read() msg.add_attachment(file_data, maintype='application', subtype='pdf', filename='faktura.pdf') # Konfiguracja SMTP (użyj SendGrid lub Gmail App Password) # with smtplib.SMTP_SSL('smtp.gmail.com', 465) as smtp: # smtp.login('USER', 'PASSWORD') # smtp.send_message(msg) print(f"[SYSTEM] Faktura wysłana do {client_email}.") ``` ### 3.
